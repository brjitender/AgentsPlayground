# Monitoring Directory

Metrics, dashboards, and observability for agents, skills, and plugins.

## Included Files

- `plugin-dashboard.md` - Plugin execution metrics
- `agent-metrics.md` - Agent performance data
- `skill-performance.md` - Skill statistics

## Metrics to Track

### Agent Metrics
- Execution time
- Success rate
- Error rate
- Decision accuracy

### Skill Metrics
- Call frequency
- Execution time
- Success rate
- Accuracy

### Plugin Metrics
- Total execution time
- Stage times
- Gate approvals
- Success rate

## Dashboards

Track daily/weekly/monthly:
- Plugin executions
- Agent success rates
- Skill performance
- Error trends
